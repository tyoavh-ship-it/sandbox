# Sandbox

Полигон для экспериментов с дизайном и прототипами. Отдельно от рабочих приложений: здесь только демо-данные и ничего не считается продакшеном.

## Структура

```
sandbox/
  index.html                 — список экспериментов
  exp/
    roadmap-3.11/
      index.html             — шаблон дорожной карты 3.11
      roadmap.json           — демо-данные (7 карточек)
```

Эксперимент — это папка в `exp/` со своим `index.html` (данные — рядом, если нужны). Чтобы добавить новый, создайте папку и строку в корневом `index.html`.

## Локальная проверка

```powershell
cd sandbox
python -m http.server 8080
```

Открыть `http://127.0.0.1:8080/`. Открытие через `file://` не подойдёт: `exp/roadmap-3.11` загружает `roadmap.json` через `fetch`, а он работает только по HTTP(S).

## Деплой в Coolify

1. Создать репозиторий `sandbox` (GitHub), положить туда содержимое этой папки, ветка `main`.
2. Coolify → New Resource → **Static Site** → GitHub-репозиторий `sandbox`.
3. Настройки: branch `main`, build command пустой, publish directory `/`, entry file `index.html`.
4. Domain: `sandbox.tautomate.ru` (A-запись на IP Coolify-VPS). HTTPS включить — сертификат Let's Encrypt Coolify выпустит и будет продлевать сам.
5. Auto deploy: вебхук на push в `main`.

В `index.html` уже стоит `<meta name="robots" content="noindex, nofollow">`, чтобы полигон не индексировался.

## Перенос эксперимента в «нормальное»

1. Эксперимент вырос → отдельный репозиторий и отдельное приложение Coolify с нормальным именем и доменом.
2. Данные — только обезличенные в песочнице; реальные появляются на этапе переноса.
3. Песочница остаётся как есть: старые эксперименты не удаляем, но и не считаем рабочими.

## Замечания

- HTTPS на каждом домене Coolify настраивает сам — отдельная возня с сертификатами не нужна.
- Если экспериментов станет много, в Coolify можно включить Preview Deployments (временные URL на каждый PR); тогда понадобится wildcard DNS `*.tautomate.ru`.
